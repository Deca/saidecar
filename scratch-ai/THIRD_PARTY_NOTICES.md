## pi-codex-search

The Codex OAuth web-search bridge in `src/codexWebSearchClient.js` adapts request-shaping and SSE parsing ideas from `pi-codex-search` version `0.1.2`.

- Package: `pi-codex-search`
- Source: https://github.com/Leechael/pi-codex-search
- License: MIT

The implementation in this project is not a Pi extension. It reads local Codex CLI auth from `~/.codex/auth.json` and uses the ChatGPT Codex backend search endpoint directly.
